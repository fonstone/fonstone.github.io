## 1. AUTOSAR OS 规范概览

### 1.1 AUTOSAR OS 的定位

AUTOSAR（AUTomotive Open System ARchitecture）OS 是 AUTOSAR 经典平台（Classic Platform）的基础软件层，其核心规范来自 OSEK/VDX 标准，并在此基础上扩展了多核、调度表（Schedule Table）、自旋锁等特性。

<MermaidDiagram chart={`graph TB
    subgraph AUTOSAR CP
        SWC[应用软件组件<br>Software Component]
        RTE[RTE<br>运行时环境]
        BSW[基础软件层<br>Basic Software]
        OS[AUTOSAR OS]
        MCU[MCU 抽象层]
        HW[硬件]
    end
    SWC --> RTE --> BSW --> OS --> MCU --> HW
`} />

AUTOSAR OS 在整个软件栈中的职责：

| 职责 | 说明 |
|------|------|
| 任务调度 | 基于优先级的抢占式/非抢占式调度 |
| 中断管理 | ISR Category 1 和 Category 2 分离 |
| 资源同步 | 优先级 Ceiling 协议防止优先级反转 |
| 事件同步 | 扩展任务间的事件通知机制 |
| 报警机制 | 基于计数器的周期性/单次报警 |
| 调度表 | 精确的周期性动作调度（AUTOSAR 扩展） |
| 多核支持 | 跨核任务激活、自旋锁、核间同步 |

### 1.2 一致性类（Conformance Classes）

AUTOSAR OS 定义了四种一致性类，从简单到复杂递增：

<MermaidDiagram chart={`graph LR
    BCC1 -->|+多激活| BCC2
    BCC1 -->|+扩展任务| ECC1
    BCC2 -->|+扩展任务| ECC2
    BCC1[BCC1<br>基本任务 1激活/任务]
    BCC2[BCC2<br>基本任务 多激活/任务]
    ECC1[ECC1<br>扩展任务 1激活/任务]
    ECC2[ECC2<br>扩展任务 多激活/任务]
`} />

| 一致性类 | 基本任务 | 扩展任务 | 每任务最大激活数 |
|----------|---------|---------|-----------------|
| BCC1 | 1激活/任务 | 不支持 | 1 |
| BCC2 | 多激活/任务 | 不支持 | 多次 |
| ECC1 | 1激活/任务 | 支持（1激活） | 1 |
| ECC2 | 多激活/任务 | 支持（多激活） | 多次 |

**选择原则**：
- 简单事件驱动场景选 BCC1（最小 ROM/RAM 开销）
- 需要等待事件的场景选 ECC1/ECC2
- 需要多激活场景（如报警周期激活同一任务）选 BCC2/ECC2

### 1.3 核心服务 API 一览

## 2. ERIKA3 整体架构设计

**关键特性**：
- 双许可：GPL + 商业许可
- 支持 AUTOSAR OS 一致性类 BCC1/BCC2/ECC1/ECC2
- 多架构：TriCore、ARM Cortex-R/M、AArch64、RISC-V 等
- 多核支持（Partitioned / Global 调度策略）
- OSEK OIL 配置语言 + 动态 API
- 与 Infineon ISAR MCAL 集成

## 3. 内核机制深度解析

### 3.1 任务管理与调度

#### 3.1.1 规范要求

AUTOSAR OS 定义了两种任务类型：

| 特性 | 基本任务（Basic Task） | 扩展任务（Extended Task） |
|------|----------------------|------------------------|
| 等待事件 | 不支持 | 支持 `WaitEvent()` |
| 状态 | SUSPENDED → READY → RUNNING | SUSPENDED → READY → RUNNING → WAITING |
| 释放资源 | 只能由自身或报警激活 | 可由事件唤醒 |
| 开销 | 较小（无事件掩码） | 较大（需要事件掩码和等待队列） |

任务状态机：

<MermaidDiagram chart={`stateDiagram-v2

    READY --> RUNNING : 调度器选中
    RUNNING --> READY : 被高优先级抢占
    RUNNING --> WAITING : WaitEvent()<br>(仅扩展任务)
    WAITING --> READY : SetEvent() 唤醒
    RUNNING --> SUSPENDED : TerminateTask()

多队列实现使用优先级位图加速查找最高优先级就绪任务，时间复杂度 O(1)：

```c
/* 调度节点插入 - 优先级排序 */
OsEE_SN * osEE_sn_priority_insert(OsEE_SN *p_head, OsEE_SN *p_sn) {
  OsEE_SN * p_prev;
  OsEE_SN * p_curr;
  p_sn->p_next = NULL;
  if (p_head == NULL) {
    return p_sn;  /* 空队列，直接插入 */
  }
  if (p_head->p_tdb->ready_prio < p_sn->p_tdb->ready_prio) {
    p_sn->p_next = p_head;  /* 新节点优先级最高，插入队首 */
    return p_sn;
  }
  /* 扫描链表，找到合适位置 */
  p_prev = p_head;
  p_curr = p_head->p_next;
  while (p_curr != NULL) {
    if (p_curr->p_tdb->ready_prio < p_sn->p_tdb->ready_prio) {
      break;
    }
    p_prev = p_curr;
    p_curr = p_curr->p_next;
  }
  p_prev->p_next = p_sn;
  p_sn->p_next = p_curr;
  return p_head;
}
```

### 3.2 报警与计数器

#### 3.2.1 规范要求

**关键实现细节**：

```c
/* osEE_counter_insert_abs_trigger - 按绝对时间插入触发器 */
void osEE_counter_insert_abs_trigger(
  OsEE_CounterDB *p_counter_db,
  OsEE_TriggerDB *p_trigger_db,
  TickType         when
) {
  OsEE_CounterCB *p_cb = p_counter_db->p_counter_cb;
  OsEE_TriggerCB *p_prev = NULL;
  OsEE_TriggerCB *p_curr = p_cb->p_first;

  /* 设置到期时间和状态 */
  p_trigger_db->p_trigger_cb->when   = when;
  p_trigger_db->p_trigger_cb->status  = OSEE_TRIGGER_ACTIVE;

  /* 按到期时间升序插入链表 */
  while (p_curr != NULL) {
    if (osEE_counter_eval_when(p_counter_db, when, p_curr->when) < 0) {
      /* 'when' 比 p_curr->when 更早到期 */
      break;
    }
    p_prev = p_curr;
    p_curr = p_curr->p_next;
  }

  if (p_prev == NULL) {
    /* 插入链表头部 - 最早到期 */
    p_trigger_db->p_trigger_cb->p_next = p_cb->p_first;
    p_cb->p_first = &p_trigger_db->p_trigger_cb;
  } else {
    p_trigger_db->p_trigger_cb->p_next = p_curr;
    p_prev->p_next = &p_trigger_db->p_trigger_cb;
  }
}
```

### 3.3 资源管理与优先级 Ceiling 协议

#### 3.3.1 规范要求

AUTOSAR OS 的资源（Resource）机制用于保护共享数据，采用 **优先级 Ceiling 协议（IPCP）** 防止优先级反转：

- 每个资源有一个 Ceiling 优先级，等于所有可能访问该资源的任务中最高优先级加一
- `GetResource()` 将任务优先级提升到 Ceiling 优先级
- `ReleaseResource()` 恢复原始优先级
- 资源必须以 LIFO（后进先出）顺序释放
- ISR2 也可以获取资源

#### 3.3.2 ERIKA3 实现

  /* 1. 校验：必须是最后获取的资源（LIFO） */
  if (p_tcb->p_last_m != &mdb[ResID].mcb) {
    return E_OS_RESOURCE;  /* 违反LIFO顺序 */

  p_tcb->p_last_m = p_tcb->p_last_m->p_next;

  /* 4. 清空持有者 */
  mdb[ResID].mcb.p_owner = NULL;

  /* 5. 重新调度（可能需要让出CPU） */
  Schedule();
  return E_OK;
}

### 3.4 事件机制

#### 3.4.1 规范要求

事件（Event）仅适用于扩展任务，用于任务间同步：

- `SetEvent(TaskID, EventMask)` - 设置指定任务的事件
- `WaitEvent(EventMask)` - 当前任务等待事件（阻塞）
- `ClearEvent(EventMask)` - 清除当前任务的事件
- `GetEvent(TaskID, EventMask)` - 获取指定任务的事件状态

#### 3.4.2 ERIKA3 实现

```c
/* 事件掩码在 TCB 中 */
struct OsEE_TCB_tag {
  /* ... */
#if defined(OSEE_HAS_EVENTS)
  EventMaskType  wait_mask;    /* WaitEvent 等待的掩码 */
  EventMaskType   event_mask;   /* 已设置的事件位 */
#endif
  /* ... */
};

/* SetEvent 实现 */
StatusType SetEvent(TaskType TaskID, EventMaskType Mask) {
  OsEE_TDB *p_tdb = &tdb_array[TaskID];
  OsEE_TCB *p_tcb = p_tdb->p_tcb;

  /* 1. 设置事件位 */
  p_tcb->event_mask |= Mask;

  /* 2. 如果任务在 WAITING 状态且等待的事件已到达 */
  if (p_tcb->status == OSEE_TASK_WAITING &&
      (p_tcb->event_mask & p_tcb->wait_mask) != 0) {
    /* 3. 唤醒任务：转入就绪队列 */
    p_tcb->status = OSEE_TASK_READY;
    /* 4. 从等待状态恢复到调度 */
    osEE_scheduler_task_unblocked(p_tdb);
  }
  return E_OK;
}

/* WaitEvent 实现 */
StatusType WaitEvent(EventMaskType Mask) {
  /* 1. 保存等待掩码 */
  p_tcb->wait_mask = Mask;

  /* 2. 检查事件是否已到达 */
  if ((p_tcb->event_mask & p_tcb->wait_mask) != 0) {
    /* 事件已到达，不需阻塞 */
    return E_OK;
  }

  /* 3. 阻塞当前任务 */
  p_tcb->status = OSEE_TASK_WAITING;
  osEE_scheduler_task_block_current();

  /* 4. 切换到下一个就绪任务 */
  osEE_hal_save_ctx_and_restore_ctx(...);
  return E_OK;
}
```

### 3.5 中断管理（ISR Cat1 / Cat2）

#### 3.5.1 规范要求

AUTOSAR OS 区分两类中断服务程序：

| 特性 | ISR Category 1 | ISR Category 2 |
|------|---------------|----------------|
| OS 管理 | 不受 OS 管理 | 受 OS 管理 |
| 优先级 | 不可被 OS 调度 | 有虚拟优先级 |
| 资源保护 | 不能使用 OS 服务 | 可使用 OS 服务 |
| 响应延迟 | 最低（直接硬件向量） | 略高（OS 封装入口/出口） |
| 用途 | 极端时间关键的外设 | 一般外设中断 |

#### 3.5.2 ERIKA3 的 ISR2 优先级映射

ERIKA3 将 ISR2 的虚拟优先级映射到 TriCore 硬件优先级：

```
虚拟优先级范围:
  0           = 空闲任务
  1..127      = 普通任务
  128..254    = ISR2 虚拟优先级
  255         = 特殊（不重新启用中断）

硬件映射:
  ISR虚拟优先级 → 硬件优先级 = 虚拟优先级 - OSEE_MAX_TASK_PRIO
  即 ISR2 的虚拟优先级 128..254 映射到硬件优先级 1..127
```

```c
/* ee_hal_internal.h - 优先级设置 */
static inline void osEE_hal_set_ipl(TaskPrio prio) {
  uint32_t ier_mask;
  uint32_t icr_val;

  if (prio == 255) {
    /* 特殊优先级：完全禁用中断 */
    osEE_hal_disableIRQ();
    return;
  }

  if (prio > OSEE_MAX_TASK_PRIO) {
    /* ISR2 优先级：映射到硬件中断优先级 */
    icr_val = (uint32_t)(prio - OSEE_MAX_TASK_PRIO);
  } else {
    /* 任务优先级：开启所有中断 */
    icr_val = 0;
  }
  /* 写入 ICR.CCPN 寄存器 */
  osEE_tc_set_icr(icr_val);
}
```

#### 3.5.3 ISR2 入口/出口封装

ERIKA3 为每个 ISR2 生成封装函数：

```c

  void isr_name##_entry(void) {                              \
    osEE_isr2_entry(isr_prio);                               \
    isr_handler();                                            \
    osEE_isr2_exit(isr_prio);                                \

/* ISR2 入口 */
void osEE_isr2_entry(TaskPrio isr_prio) {
  OsEE_CCB *p_ccb = osEE_get_curr_core()->p_ccb;
  /* 1. 保存当前中断嵌套计数 */
  p_ccb->isr_nesting++;
  /* 2. 设置 ISR2 上下文 */
  p_ccb->os_context = OSEE_TASK_ISR2_CTX;
  /* 3. 提升当前优先级到 ISR2 的虚拟优先级 */
  osEE_hal_set_ipl(isr_prio);
}

/* ISR2 出口 */
void osEE_isr2_exit(TaskPrio isr_prio) {
  OsEE_CCB *p_ccb = osEE_get_curr_core()->p_ccb;
  /* 1. 恢复中断嵌套计数 */
  p_ccb->isr_nesting--;
  /* 2. 恢复上一个上下文 */
  p_ccb->os_context = /* 之前保存的上下文 */;
  /* 3. 恢复优先级 */ 
  osEE_hal_set_ipl(/* 之前保存的优先级 */);
  /* 4. 检查是否需要重新调度 */
  osEE_scheduler_task_preemption_point();
}

## 5. 实战：从 OIL 配置到任务运行

### 5.1 OIL 配置文件（conf.oil）

以下完整示例来自 ERIKA3 TC38x 的 CAN MCAL 示例，展示了如何配置一个完整的 AUTOSAR OS 应用：

```
CPU mySystem {
  OS myOs {
    /* 编译选项 */
    EE_OPT = "OS_EE_APPL_BUILD_DEBUG";
    EE_OPT = "OSEE_DEBUG";
    EE_OPT = "OSEE_BYPASS_CLOCK_CONFIGURATION";

    /* 链接选项 */
    LDFLAGS = "-Wl,--gc-sections";

    /* 调度配置 */
    USERESSCHEDULER = FALSE;         /* 使用优先级调度，非用户调度 */

    CPU_DATA = TRICORE {
      MULTI_STACK = TRUE;             /* 多栈支持（扩展任务必需） */
      COMPILER = GCC { MINIMAL_OPTS = TRUE; };
      IDLEHOOK = TRUE { HOOKNAME = "idle_hook"; };  /* 空闲钩子 */
      CPU_CLOCK = 80.0;              /* 80 MHz CPU 时钟 */
    };

    MCU_DATA = TC27X {
      DERIVATIVE = "tc277tf";
      REVISION = "D";
    };

    /* 库配置 - ISAR MCAL */
    LIB = ISAR_MCAL {
      VERSION = "6.0.0";
      STAND_ALONE = TRUE;            /* 独立模式(不依赖完整BSW) */
      MCU_DRIVER = TRUE;             /* MCU 驱动 */
      PORT_DRIVER = TRUE;            /* PORT 驱动 */
      IRQ_DRIVER = TRUE;             /* 中断驱动 */
      CAN_DRIVER = TRUE;             /* CAN 驱动 */
      USE_DET = TRUE;                /* 默认错误跟踪 */
      DIO_DRIVER = TRUE;             /* DIO 驱动(用于LED) */
    };

    /* 一致性类 */
    KERNEL_TYPE = OSEK { CLASS = BCC1; };
  };

  /* 应用代码 */
  APPDATA myApp {
    APP_SRC = "code.c";
    APP_SRC = "CanIf_Cbk.c";
  };

  /* 硬件计数器 */
  COUNTER SystemTimer {
    MINCYCLE = 1;
    MAXALLOWEDVALUE = 65535;       /* 16-bit 计数值 */
    TICKSPERBASE = 1;
    TYPE = HARDWARE {
      SYSTEM_TIMER = TRUE;          /* 系统定时器 */
      PRIORITY = 1;                 /* 定时器中断优先级 */
      DEVICE = "STM_SR0";           /* System Timer Module */
    };
    SECONDSPERTICK = 0.001;         /* 1ms tick */
  };

  /* 报警 - 周期激活任务 */
  ALARM AlarmTask1 {
    COUNTER = SystemTimer;
    ACTION = ACTIVATETASK { TASK = Task1; };
    AUTOSTART = TRUE { ALARMTIME = 10; CYCLETIME = 10; };
    /* 10ms 周期激活 Task1 */
  };

  ALARM AlarmTask2 {
    COUNTER = SystemTimer;
    ACTION = ACTIVATETASK { TASK = Task2; };
    AUTOSTART = TRUE { ALARMTIME = 500; CYCLETIME = 500; };
    /* 500ms 周期激活 Task2 */
  };

  /* 基本任务定义 */
  TASK Task1 {
    PRIORITY = 1;                   /* 优先级 1 */
    SCHEDULE = FULL;                /* 全抢占式 */
  };

  TASK Task2 {
    PRIORITY = 2;                   /* 优先级 2 */
    SCHEDULE = FULL;                /* 全抢占式 */
  };

  /* ISR Category 2 定义 */
  ISR Can0_Tx {
    CATEGORY = 2;                   /* ISR Category 2 */
    SOURCE = "CANINT0";             /* CAN 发送中断源 */
    HANDLER = "CANSR0_ISR";
    PRIORITY = 3;                   /* ISR2 优先级 */
  };

  ISR Can0_Rx {
    CATEGORY = 2;
    SOURCE = "CANINT4";             /* CAN 接收中断源 */
    HANDLER = "CANSR4_ISR";
    PRIORITY = 4;
  };
};

### 5.2 应用代码（code.c）

```c
#include "ee.h"          /* ERIKA3 主头文件，包含所有 OS API */

/* 任务声明 */
DeclareTask(Task1);
DeclareTask(Task2);

/* 全局变量 */
OsEE_reg volatile task1_fired, task1_ended;
OsEE_reg volatile task2_fired, task2_ended;

int main(void) {
  /* === 硬件初始化（在 StartOS 之前） === */
  Mcu_Init(&Mcu_ConfigRoot[0]);            /* MCU 初始化：时钟、Flash 等待等 */
  Port_Init(&Port_ConfigRoot[0]);           /* PORT 初始化：引脚复用、方向等 */
  Dio_Init(&Dio_ConfigRoot[0]);             /* DIO 初始化：LED 等 */
  Can_17_MCanP_Init(&Can_17_MCanP_ConfigRoot[0]); /* CAN 初始化 */

  Mcu_InitClock(0);                        /* 配置 PLL 锁相环 */
  while (Mcu_GetPllStatus() != MCU_PLL_LOCKED);    /* 等待 PLL 锁定 */
  Mcu_DistributePllClock();                 /* 切换到 PLL 时钟 */

  /* === 启动 AUTOSAR OS === */
  StartOS(OSDEFAULTAPPMODE);

  /* StartOS 不会返回 */
  return 0;
}

/* === Task1: CAN 主处理任务（10ms 周期） === */
TASK(Task1) {
  ++task1_fired;
  osEE_test_toggle_dio(OSEE_TEST_DIO_OUT_1);  /* 翻转 LED */

  /* 首次激活时初始化 CAN 控制器 */
  if (can_init == OSEE_CAN_MODE_NOT_INITIALIZED) {
    can_init = OSEE_CAN_MODE_INITIALIZED;
    Can_17_MCanP_SetControllerMode(CanController_0, CAN_T_START);
    Can_17_MCanP_EnableControllerInterrupts(CanController_0);
  }

  /* CAN 主处理函数 */
  Can_17_MCanP_MainFunction_Write();  /* CAN 发送主函数 */
  Can_17_MCanP_MainFunction_Read();   /* CAN 接收主函数 */
  Can_17_MCanP_MainFunction_Mode();   /* CAN 模式管理 */

  ++task1_ended;
  TerminateTask();  /* 标准任务终止 */
}

/* === Task2: CAN 发送任务（500ms 周期） === */
TASK(Task2) {
  static uint8 msg_id = 0;
  ++task2_fired;

  /* 准备 CAN 报文并发送 */
  msg_id = (msg_id + 1) % OSEE_TEST_NUMBER_OF_CAN_MESSAGES;
  Can_17_MCanP_Write(OSEE_TEST_CAN_HWH_TX, &PduInfo_1[msg_id]);

  osEE_test_toggle_dio(OSEE_TEST_DIO_OUT_2);  /* 翻转 LED */
  ++task2_ended;
  TerminateTask();
}

/* === 空闲钩子函数 === */
void idle_hook(void) {
  /* 栈监控 - 检测栈溢出 */
  OsEE_addr volatile curr_sp = osEE_get_SP();
  static OsEE_addr main_sp = 0;
  if (main_sp == 0) {
    main_sp = curr_sp;
  } else if (main_sp != curr_sp) {
    OSEE_BREAK_POINT();  /* 栈指针变化异常！ */
  }
}
```

**两种多核调度策略**：

| 策略 | 描述 | 适用场景 |
|------|------|---------|
| **Partitioned** | 每核独立就绪队列，任务绑定到指定核 | 低延迟、可预测性要求高 |
| **Global** | 全局就绪队列，任务可在核间迁移 | 负载均衡、利用率优先 |

### 6.2 自旋锁（Spinlock）

```c
/* 自旋锁 API（AUTOSAR OS 多核扩展） */
StatusType GetSpinlock(SpinlockIdType SpinlockID);
StatusType ReleaseSpinlock(SpinlockIdType SpinlockID);
StatusType TryToGetSpinlock(SpinlockIdType SpinlockID, TryToGetSpinlockType *Success);

/* ERIKA3 实现 */
StatusType GetSpinlock(SpinlockIdType SpinlockID) {
  OsEE_MDB *p_mdb = &kdb->p_spinlock_mdb_array[SpinlockID];
  
  /* 1. 自旋等待直到锁可用 */
  while (osEE_hal_test_and_set(&p_mdb->mcb.lock) != 0) {
    /* 自旋 */ 
  }
  
  /* 2. 记录锁持有信息 */
  p_mdb->mcb.p_owner = osEE_get_curr_tdb();
  p_mdb->mcb.p_next = p_tcb->p_last_m;
  p_tcb->p_last_m = &p_mdb->mcb;
  
  return E_OK;
}
```

## 7. 总结与参考

### 7.1 ERIKA3 架构优势总结

| 维度 | 特性 | 实现方式 |
|------|------|---------|
| **可配置性** | ROM/RAM 开销可裁剪 | DB/CB 分离，`OSEE_HAS_*` 宏控制特性 |
| **一致性类** | BCC1/BCC2/ECC1/ECC2 | OIL 配置，运行时可通过 `KERNEL_TYPE` 切换 |
| **多核** | Partitioned + Global 调度 | Per-Core CDB/CCB + Global KDB/KCB |
| **确定性** | O(1) 调度（多队列位图） | `OSEE_RQ_MULTIPLEQUEUE` 配置 |
| **平台适配** | CSA 原生上下文管理 | TriCore HAL 充分利用硬件 CSA |
| **MCAL 集成** | ISAR MCAL 支持 | contrib/infineon 适配层 |
| **双许可** | GPL + 商业 | 灵活满足不同场景 |
