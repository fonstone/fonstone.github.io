## 1. 向着 Linux Kernel 出发——加载引导（ch11-1）

### 1.1 kernel 编译


bootfs 含三个文件，**boot.scr**（U-Boot 脚本）：

```
load virtio 0:1 0x80000000 /Image
load virtio 0:1 0x82000000 /quard_star.dtb
booti 0x80000000 - 0x82000000
```

用 `mkimage` 转换：

```bash
mkimage -A riscv -O linux -T script -C none -a 0 -e 0 \
  -n "Distro Boot Script" -d quard_star_uboot.cmd boot.scr
```

分区格式化脚本 `generate_rootfs.sh`：

```bash
losetup -o 0 --sizelimit 1073741824 /dev/loop70 $1 -P
echo -e "I\n$2\nw\n" | fdisk /dev/loop70
losetup -d /dev/loop70
losetup -o 0 --sizelimit 1073741824 /dev/loop70 $1 -P
mkfs.vfat /dev/loop70p1
mkfs.ext4 /dev/loop70p2
losetup -d /dev/loop70
```

## 2. 向着 Linux Kernel 出发——完成启动（ch11-2）

### 2.1 编写测试 init 进程

```c
// target_root_app/init_test/main.c
#include <stdio.h>
#include <unistd.h>
#include <pthread.h>

int main() {
    pid_t result = fork();
    if (result == 0) { printf("In child!! My PID is %d\n", getpid()); }
    else {
        printf("In father!! My PID is %d\n", getpid());
        for(;;) { printf("PID%d:hello world!\n", getpid()); sleep(1); }
    }
    pthread_t th;
    pthread_create(&th, NULL, thread0, NULL);
    pthread_create(&th, NULL, thread1, NULL);
    for(;;) { printf("PID%d:hello world!\n", getpid()); sleep(1); }
}
```

```bash
$CROSS_PREFIX-gcc main.c -lpthread -static -o init  # 静态编译
```

注意 init 进程不可退出，否则触发 `panic: Attempted to kill init!`。

## 3. busybox（ch12）

### 3.1 编译

```bash
cd busybox-1.33.1
```

### 4.2 配置文件

**/etc/inittab**：

```
::sysinit:/etc/init.d/rcS
console::askfirst:-/bin/sh
```

**/etc/init.d/rcS**：

```sh
#! /bin/sh
PATH=/sbin:/bin:/usr/sbin:/usr/bin
/bin/mount -a
/sbin/mdev -s
/bin/mount -a
echo " Welcome debugging on Qemu Quard Star board! "
```

**/etc/fstab**：

```
proc     /proc              proc    defaults 0 0
none     /tmp               ramfs   defaults 0 0
sysfs    /sys               sysfs   defaults 0 0
mdev     /dev               ramfs   defaults 0 0
debugfs  /sys/kernel/debug  debugfs defaults 0 0
```

`mount -a` 读取 fstab 自动挂载；`mdev -s` 通过查询 `/sys/dev` 自动创建 `/dev` 设备节点。

```bash

$CROSS_PREFIX-readelf -l busybox  # 查看段信息
# INTERP 段: [Requesting program interpreter: /lib/ld-linux-riscv64-lp64d.so.1]

# 列出所有动态依赖（类似 ldd）
```

解释器源码位于 `glibc/elf/rtld.c:1124:dl_main`。从交叉编译工具链 sysroot 拷贝解释器与相关 lib 库到目标文件系统 `/lib`。本节 tag：`ch14`。

## 6. Linux 多用户管理（ch15）

### 6.1 inittab 修改

从 `-/bin/sh` 改为 `getty`+`login`：

```
::sysinit:/etc/init.d/rcS
console::respawn:/sbin/getty 38400 console
console::restart:/sbin/init
console::ctrlaltdel:/sbin/reboot
::shutdown:/etc/init.d/rcK
::shutdown:/sbin/swapoff -a
::shutdown:/bin/umount -a -r
```

## 7. 阶段小结

本篇是整个教程的"心脏"——系统真正跑起来了。关键要点：

- **内核启动两阶段**：early boot（汇编，页表/MMU/异常向量）→ start_kernel（C 代码）
- **busybox 万剑归宗**：所有工具软连接到单一 busybox，按 argv[0] 分发
- **init 进程不可退出**：退出即 panic
- **动态链接三要素**：`.interp` 指向解释器 → 解释器加载依赖 so → 真正可执行文件
- **多用户三文件**：passwd（用户）、group（组）、shadow（密码）
