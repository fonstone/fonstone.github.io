## 1. kgdb 调试 Linux 内核与驱动模块（ext1）

### 1.1 修改内核配置

| 配置项 | 作用 |
|--------|------|
| `CONFIG_KGDB=y` | 启用 kgdb |
| `CONFIG_GDB_SCRIPTS=y` | 生成 `vmlinux-gdb.py`，提供 gdb 扩展命令 |
| `CONFIG_DEBUG_INFO=y` | 生成调试信息 |
| `CONFIG_DEBUG_INFO_DWARF4=y` | DWARF4 信息（否则无法 debug 变量） |
| 关闭 `STRICT_KERNEL_RWX`/`STRICT_MODULE_RWX` | 允许软件断点写入内核代码段 |

### 1.2 修改内核启动参数

```
bootargs = "root=/dev/vda2 rw console=ttyS0 earlycon=sbi nokaslr kgdboc=ttyS1,115200 kgdbwait"
```

### 1.4 调试技巧

内核调试是**被动调试**——`echo g > /proc/sysrq-trigger` 触发 breakpoint。`lx-symbols` 自动加载 ko 符号。

## 2. gcc -pg 编译选项在嵌入式 profile 中应用（ext2）

<MermaidDiagram chart={`flowchart TD
    A["gcc -pg 编译选项"] --> B["所有函数前插入 _mcount 调用"]
    B --> C["_mcount 读取 ra 寄存器<br/>获取调用者地址"]
    C --> D["统计 curr_ra 计数"]
    D --> E["分析高频调用函数<br/>进行优化"]
    C --> F["caller_ra 参数<br/>可 hook 返回地址统计执行时间"]
    C --> G["通过串口/USB 发送 PC<br/>实时分析或存储脱机分析"]
`} />

```c
void __attribute__((no_instrument_function)) _mcount(uint64_t caller_ra) {
    uint64_t curr_ra;
    __asm__ __volatile__("mv %0, ra":"=r"(curr_ra));
    profiling(curr_ra - 4);
}
```

### 3.1 网络设备

**user 模式**（免配置）：

```bash
-netdev user,id=net0,net=192.168.31.0/24,dhcpstart=192.168.31.100,hostfwd=tcp::3522-:22
```

**tap 模式**（需宿主机配网桥，无线网卡一般不支持）：

```bash
-netdev tap,ifname=tap0,script=no,downscript=no,id=net0
```

### 3.2 调试选项

```bash
-s -S                    # 启动 gdb 服务(端口1234)并等待连接
-d in_asm/int/page/mmu -D qemu.log  # 输出 guest 运行时信息
```


## 6. 嵌入式 Linux 上 ifplugd 的使用配置与 qemu 模拟验证（ext6）

### 6.1 启动脚本与配置

**/etc/init.d/S50ifplugd.sh**：

```sh
#! /bin/sh
source /etc/ifplugd/ifplugd.conf
case "$1" in
  start)
    for i in $INTERFACES; do
      /usr/sbin/ifplugd -pq -t1 -u1 -d1 -i $i -r /etc/ifplugd/ifplugd.action
    done ;;
  stop)
    for i in $INTERFACES; do kill $(cat /var/run/ifplugd.$i.pid); done ;;
esac
```

**/etc/ifplugd/ifplugd.conf**：`INTERFACES="eth0 eth1"`

**/etc/ifplugd/ifplugd.action**：

```sh
case "$2" in
  up)   /sbin/ifup $1   ;;
  down) /sbin/ifdown $1 ;;
esac
```

### 6.2 qemu 模拟网口插拔

qemu monitor 终端输入即可模拟真实板卡网口插拔：

```
set_link net0 off
set_link net0 on
```

| 1 | QEMU 环境与板卡 | QEMU 板卡注册、内存映射、RISC-V 上电约定 |
| 2 | OpenSBI 与设备树 | 多级 Boot、SBI 规范、FDT、Domain 隔离 |
