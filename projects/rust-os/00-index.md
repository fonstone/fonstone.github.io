# 从零写 Rust RTOS

在 QEMU 模拟的 ARM Cortex-R52 上从零实现一个 RTOS。章节按 rCore 风格的实验序列组织：先建立执行环境与裸机程序，再逐步加串口驱动、异常向量表、系统定时器、上下文切换、抢占式调度器、同步原语与任务间通信，中间穿插 Rust 系统编程与 RISC-V 汇编附录。

## 课程信息

- 难度：深入
- 章节数：89 章
- 前置要求：已掌握 Rust 所有权与 unsafe 边界；了解 ARM 异常模型；看懂汇编级别的上下文保存
- 学完能拿到：实现可抢占的多任务调度器；完成异常向量表与系统定时器驱动；在 QEMU 上跑通任务间通信
- 课程首页（含学习进度）：[/projects/rust-os](/projects/rust-os)
